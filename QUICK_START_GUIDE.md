## 🛠️ Troubleshooting

### **System Won't Start**
1. Check Python is installed: `python --version`
2. Must be Python 3.9 or higher
3. Run as Administrator if needed
4. Check port 5000 is available

### **Chatbot Not Responding**
1. Check browser console for errors (F12)
2. Refresh the page
3. Clear browser cache
4. Check Flask server is running

### **UI Looks Broken**
1. Hard refresh: `Ctrl + F5`
2. Clear browser cache
3. Check `enhanced-styles.css` is loaded
4. Try different browser (Chrome/Edge recommended)

### **Dependencies Missing**
```bash
# Reinstall all packages:
pip install -r requirements.txt --force-reinstall
```

## 🤝 Support

### **Common Questions:**

**Q: Can I customize the colors?**
A: Yes! Edit `enhanced-styles.css` color variables.

**Q: How do I add more chatbot responses?**
A: Edit the `_rule_chat()` function in `flask_app.py`.

**Q: Can I use Claude AI instead of rule-based chat?**
A: Yes! Set `ANTHROPIC_API_KEY` in `.env` file.

**Q: How do I deploy to production?**
A: Use `gunicorn flask_app:app -c gunicorn.conf.py`.

**Q: Is the system open source?**
A: Check the LICENSE file in the project root.
